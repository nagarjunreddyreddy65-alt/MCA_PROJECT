    Safety Engine Philosophy: Fail-Safe, Not Fail-Open

    • Risk Protection: If the Random Forest failure classifier predicts an upcoming pipeline failure risk $\ge 70\%$, test reduction is strictly prohibited.

    • Uncertainty Mitigation: If the model's confidence is $< 65\%$, optimization is bypassed, guaranteeing that low certainty never leads to false test omission.

    • Zero Silent Drops: If any modified file is non-Python (YAML, Docker, requirements), has syntax errors, or lacks test mappings, the system automatically falls back to full regression testing.
